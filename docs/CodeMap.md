# Code map

Where things live and which files a typical change touches. Read this first; open the full docs only for the section you need (links below). Keep it short: one line per file, update it when you add, rename or delete a file.

Rules and reasons: [Architecture](Architecture.md), [Subsystems](Subsystems.md), [Resource creation](ResourceCreation.md), [Scene, ECS and systems](SceneAndECS.md), [Test bed](TestBed.md). Unfinished work is tagged in code: search `TODO(assets)` (and `Known gaps` in each doc).

## Gotchas

- **Box2D** is a git submodule at `Hydro/vendor/box2d`, pinned to v3.1.1 (`git submodule update --init Hydro/vendor/box2d`). `Hydro/vendor/box2d.premake5.lua` builds it as a C17 static library; Debug is optimised on purpose (see the comment there). Only `Physics/` includes `<box2d/box2d.h>`.
- **Jolt Physics** is a git submodule at `Hydro/vendor/JoltPhysics`, pinned to v5.6.0 (`git submodule update --init Hydro/vendor/JoltPhysics`). `Hydro/vendor/JoltPhysics.premake5.lua` builds it as a C++17 static library with no debug renderer, profiler, object stream or AVX; the same defines (`JoltDefines()` in `Dependencies.lua`) must be used by every project that includes Jolt headers. Only `Physics/` includes `<Jolt/...>`.
- **cgltf** (vendored single header `Hydro/vendor/cgltf/cgltf.h`, v1.14, MIT): the glTF reader; its implementation is compiled in `Renderer/MeshImporter.cpp` (`CGLTF_IMPLEMENTATION`). It replaced tinyobjloader (`Hydro/vendor/Obj-loader`, unused).
- **ImGuizmo** (vendored `Hydro/vendor/ImGuizmo/ImGuizmo.h` / `.cpp`, MIT; commit in its `README.txt`): the Editor window's transform gizmo. Compiled into **Oxygen** only (`Oxygen/premake5.lua`, warnings off), included as `<ImGuizmo.h>` (`IncludeDir.ImGuizmo`); the engine never uses it.
- **Old EnTT** (vendored single header `Hydro/vendor/entt/entt.hpp`, no version macro): `registry.has<T>`, `view.get<A, B>(e)`; no `all_of`/`any_of` (upgrade is Roadmap E2).
- **Line endings**: CRLF in the working copy for sources and docs (`.gitattributes`); `*.sh` is LF.
- **Style**: `namespace Hydro` only, no `!` (use `== false` / `== nullptr`), braces on every body, `m_PascalCase`. See the skill or [Architecture](Architecture.md#code-conventions).
- `Renderer2D.h` and `Renderer.h` still include `vulkan.h` (A7; `RenderView.h` no longer does); don't add Vulkan to other `Renderer/` headers.
- Shaders are compiled at runtime by shaderc from `assets/shaders/...`, relative to the working directory (run Oxygen from the `Oxygen/` folder).

## Checking without Windows

`scripts/fonts/make_bmfont.py <font.ttf> --size <px> --out <Assets path without extension>`: bakes a TTF / OTF into a BMFont (`.fnt` + one PNG page, pixel fonts without anti-aliasing at their native size, `--smooth` for others; ASCII, Latin-1 and typographic punctuation; kerning) and writes the page's `.hymeta` (Nearest for a pixel font, Linear with `--smooth`; Clamp) and the font's, with fresh handles, when missing (Pillow, fontTools). `Assets/Fonts`: `PixelifySans11` (11 px), and the game's smooth fonts `EBGaramond30`, `EBGaramond22`, `Cinzel34`, `Cinzel20` (`--smooth --page-width 512 --padding 2`, from the OFL fonts' Latin subsets; licences next to them).

`scripts/ui/make_ui_art.py`: draws `Assets/UI` (the runtime UI's frames, ribbons, cursor and markers; Pillow). `scripts/ui/build_game_ui.py [battle] [field]`: rebuilds the runtime UI of `Battle.hyscene`, `ShrineGlade.hyscene` and `FarmVillage.hyscene` (removes its own and the replaced entities by tag, appends them again with IDs from their tags; close the scenes first; PyYAML). `scripts/ui/preview_ui.py <scene> --out file.png [--canvas name] [--show / --hide name] [--focus button] [--world "Canvas=x,y"] [--background image] [--size w h]`: draws a scene's runtime UI offline as the engine lays it out (rects, layout groups, scroll views, nine-slice, BMFont text, tints, focus visibility).

`scripts/compare_captures.py a.png b.png [--out diff.png]`: compares two view captures (Capture menu, F9) pixel by pixel; exit code 0 when they match (Pillow).

`scripts/check_texel_density.py <scene> [--assets DIR] [--target 32] [--tolerance 0.2] [--all] [--strict]`: lists the sprites, shape materials and model materials (`.glb` UVs) of a scene drawn outside the world density (32 texels per metre, [Sprite sizes](SpriteSizes.md#world-density-32-texels-per-metre-decided-2026-10-30)); PyYAML, numpy for models.

`scripts/snap_pixel_texture.py in.png out.png [--period N] [--scale F] [--colors N] [--no-tile]`: turns "fake pixel art" (art pixels drawn as N x N blocks) into a clean texture: snaps to the real grid, makes organic surfaces tile (edge fold), quantises to a palette, prints the material Tiling for 32 texels per metre (Pillow, numpy).

`scripts/check.sh [files...]`: g++ `-fsyntax-only -Wall -Wextra` over the engine and editor sources (Windows-only files skipped) and glslang over the shaders. Linux/WSL; downloads Vulkan-Headers, shaderc headers and builds glslang once into `/tmp/hydro-check`. Not a substitute for an MSVC `/W4` build.
